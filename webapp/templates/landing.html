The language challenge

Pakistan's food reviews are written in a beautiful mix of English, Roman Urdu (Urdu in Latin script, with no fixed spelling), and Urdu Nastaliq script. A single model can't handle all three well — that's why we built a language-aware routing system.

The complete pipeline, step by step

From raw CSVs to interactive dashboards — every stage is measured, benchmarked, and documented. No black boxes.

1

Data Ingestion & Deduplication

pandas

Two yearly Foodpanda exports (2025 + 2026) merged on storeid. UUID-based deduplication removed 139,159 duplicate snapshots — a naive concatenation would have double-counted 9% of the data. Final: 1,552,204 unique reviews, Feb 2024 – Jan 2026.

2

Language Detection

regexlexicon

Each review classified as English, Roman Urdu/Mixed, or Urdu Script using Unicode range detection (U+0600–U+06FF) and a 50+ word Roman Urdu marker lexicon. Language flag determines which model handles the review.

3

Model Benchmarking

XLM-RoBERTaTweetEval

Two transformer models benchmarked on held-out labeled data before any production use. Khubaib01/roman-urdu-sentiment-xlm-r achieved 67.9% accuracy on Roman Urdu (vs. 48.8% for the general model). cardiffnlp/twitter-xlm-roberta-base-sentiment achieved 68.0% on English TweetEval. A data-driven VADER lexicon baseline was also built for comparison.

4

Dual-Transformer Ensemble Inference

PyTorchCUDA fp16

Both models run on every review with GPU-accelerated batch inference (batch size 128, mixed precision on CUDA). Each review gets two predictions + confidence scores. Checkpointed every 200 batches for crash recovery on Kaggle GPU sessions.

5

Language-Aware Routing

confidenceagreement

Roman Urdu/Mixed reviews route to the specialist model; English/Urdu Script to the general model. Reviews where models disagree or confidence drops below 0.60 are flagged for LLM review — creating a transparent "uncertainty queue" rather than silently trusting a single prediction.

6

Keyword-Based Aspect Extraction

multilingual

Seven aspect categories (taste, quantity, price, delivery, packaging, hygiene, service) detected via a multilingual keyword dictionary covering English and Roman Urdu terms. Text normalization collapses repeated characters (boooht → boht) before matching.

7

Zero-Shot Aspect Discovery

mDeBERTa-v310k sample

A cross-lingual NLI model (MoritzLaurer/mDeBERTa-v3-base-mnli-xnli) run on 10,000 "blind spot" reviews (those with zero keyword aspects) to discover what the keyword list misses. Surfaced new candidate categories like "wrong item received" and "food arrived cold". Limited to 10k due to student compute constraints.

8

Unsupervised Topic Modeling

BERTopicMiniLM-L12

100,000 reviews embedded with paraphrase-multilingual-MiniLM-L12-v2, then clustered via BERTopic with a custom Roman Urdu stopword list. Discovered organic topic clusters that neither the keyword list nor zero-shot classifier anticipated.

9

SHAP Explainability

SHAPword-level

SHAP (SHapley Additive exPlanations) applied to explain individual predictions — which specific words drove each sentiment label. Used on LLM-queued reviews to understand why the ensemble was uncertain, surfacing patterns like Roman Urdu function words confusing the general model.

10

Aggregation & Web Platform

DuckDBFlask

All results aggregated at city, restaurant, and aspect level. Temporal trends computed monthly. City reliability scores measure model agreement rate by region. Data served via Flask + DuckDB to this interactive web platform with Chart.js visualizations.

Under the hood: transformer architecture

Two fine-tuned XLM-RoBERTa models, routed by detected language, with disagreement-based uncertainty flagging.

G

cardiffnlp (General Multilingual)

XLM-RoBERTa-base · 8 languages · TweetEval fine-tuned

Architecture: 12-layer transformer, 270M parameters

Strength: English benchmark — 68.0% accuracy on TweetEval sentiment

Weakness: 48.8% on Roman Urdu — function words like "acha", "bohat" confuse it

Routing: Handles English and Urdu Script reviews

R

Khubaib01 (Roman Urdu Specialist)

XLM-RoBERTa · Roman Urdu fine-tuned

Architecture: XLM-R base, fine-tuned on Roman Urdu sentiment data

Strength: 67.9% accuracy on Roman Urdu benchmark — a +19 point improvement

Weakness: Underperforms on pure English

Routing: Handles Roman Urdu / Mixed-language reviews
